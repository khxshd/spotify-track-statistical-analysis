# Publication notes

This portfolio copy was prepared from the original Spring 2026 project files. The original school folders were preserved.

- Only the project code and deliverables named in this repository were selected.
- Existing local Git history, notebook checkpoints, editor settings, grading materials, exam answers, unrelated coursework and personal documents were excluded.
- PDFs were rebuilt without document metadata, annotations, active links, forms or attachments. Project authorship credits were preserved.
- Figure PNGs were extracted from the reviewed final report and rewritten without original metadata.
- Raw datasets are downloaded separately from their credited sources. Archives are not included.
- Published text files, extracted PDF text and Git history were checked for credential patterns with Gitleaks. The R code images in the report appendix were also reviewed visually before publication.

Keep future API credentials in environment variables. Never paste keys into notebooks, reports, screenshots or recordings. Run a secret scanner before publishing new commits.
